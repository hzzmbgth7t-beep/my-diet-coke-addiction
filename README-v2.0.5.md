# My Diet Coke Addiction - Version 2.0.5

## Changes in V2.0.5

- Replaced the main total ounces display with carbonated ounces
- Selected-date totals now show carbonated ounces instead of total ounces
- Report totals now show carbonated ounces instead of total ounces
- After Save Entry:
  - entry form resets
  - app returns to the Home screen
- After Save Changes:
  - edit form resets
  - app stays on the selected-date entry page
  - selected-date entry list remains expanded
  - “✓ Changes Saved” briefly appears
- Copy Entry:
  - duplicates the selected entry
  - sets copied entry time to the current time
  - opens the copied entry for review/editing
